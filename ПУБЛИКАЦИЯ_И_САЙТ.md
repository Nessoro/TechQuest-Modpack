# Как запустить GitHub-репозиторий и сайт TechQuest

## Быстрее всего — через ChatGPT с подключённым GitHub

1. Войдите в GitHub под аккаунтом **Nessoro** и создайте **новый публичный пустой репозиторий** с названием `TechQuest-Modpack` на странице https://github.com/new. Не добавляйте README, `.gitignore` или лицензию: они уже есть в проекте.
2. Напишите в чате «Репозиторий `Nessoro/TechQuest-Modpack` создан, загрузи файлы». Если подключённая интеграция GitHub разрешает запись в новый репозиторий, ассистент сможет разместить подготовленные файлы, не требуя от вас Git на компьютере.
3. На GitHub зайдите в `Nessoro/TechQuest-Modpack` → **Settings → Pages**. Выберите **Deploy from a branch**, ветка `main`, каталог `/docs`, нажмите **Save**.
4. В **Settings → General → Features** проверьте, что **Issues** включены.
5. На опубликованном сайте проверьте каталог модов, форму «Сообщить о проблеме» и «Предложить мод». Заявки публикуются в GitHub Issues **после авторизации и подтверждения**. У сайта нет собственной базы данных.

Опубликованный сайт: `https://nessoro.github.io/TechQuest-Modpack/`. GitHub Pages настроен, автоматическая публикация прошла успешно.

## Альтернатива: отправка с Windows 11

1. Распакуйте архив `TechQuest-Modpack_0.1.0_Repo-and-Site.zip` в отдельный каталог.
2. Установите **Git for Windows** и войдите в свой GitHub (например, через Git Credential Manager).
3. Создайте **пустой публичный** `Nessoro/TechQuest-Modpack` как в инструкции выше.
4. Запустите `ОПУБЛИКОВАТЬ_НА_GITHUB.bat` из распакованной папки. Если Git запросит имя/email автора коммита, настройте их локально. При первом push потребуется авторизация.
5. Настройте GitHub Pages и Issues по пунктам 3–5 первого раздела.

## Что уже готово, а что пока нет

**Готово:** статический адаптивный сайт, каталог из `modlist.json`, формы ошибок и предложений, отображение открытых Issues, шаблоны Issues, проверки GitHub Actions, генератор клиентского `.mrpack` и набор серверных модов.

**Пока не готово:** полноценное тестирование запуска игрового клиента, сервера и промышленной автоматизации. Генератору нужен интернет для разрешения версий на Modrinth. IC2 уже загружен в `manual-mods/` и включён в `.mrpack` с закреплённым URL и контрольными суммами.

Файл IC2 Nostalgia находится в публичном GitHub-репозитории; остальные JAR загружаются из Modrinth. Публичное размещение IC2 следует перепроверить на соблюдение условий всех правообладателей. Перед первым общим серверным запуском обязательно проверьте список модов и совместимость ядра BuildCraft+IC2, а также сделайте резервную копию мира.
