# TechQuest Hybrid Warfare Armor — экспериментальный аддон

**Статус: prototype / draft, не проверено запуском Minecraft.** Платформа: Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21. Этот код дополняет существующий TechQuest-Modpack, но **не включён в его `modlist.json`** до полной проверки.

## Предметы и рецепты

Скрипт `scripts/generate_assets.py` создаёт 20 новых гибридных предметов:
4 направления (IC2: Nostalgia, Modern Industrialization, Mekanism, Oritech) × 5 базовых предметов Superb Warfare 0.8.9.2.

Исходники Superb Warfare подтверждают:
- `superbwarfare:ru_chest_6b43` и `superbwarfare:ru_helmet_6b47`
- `superbwarfare:us_chest_iotv` и `superbwarfare:us_helmet_pasgt`
- `superbwarfare:ge_helmet_m_35`

**Кузнечный стол:** Netherite Upgrade Template + оригинальный бронежилет/шлем Superb Warfare + броня соответствующего слота из одного из четырёх технических модов → гибридная версия. Существующее оборудование-донор расходуется **без сохранения его энергии и модулей**, поэтому до адаптеров такое сочетание не рекомендуется использовать в основном мире.

Код создаёт собственные предметы с ванильной 3D-геометрией брони и повторяет значения атрибута `superbwarfare:bullet_resistance` для исходных шлемов и жилетов, включая уменьшение защиты при износе. Поведение бронепластин Superb Warfare на новых предметах пока не проверено.

Когда совпадают технологические направления шлема и жилета, прототип даёт один небольшой пассивный эффект: IC2 — огнестойкость, MI — Сопротивление I, Mekanism — дыхание под водой, Oritech — скорость I. Это **не** настоящие EU/FE, встроенные энергосистемы, оригинальные Jetpack или модули MekaSuit.

## Четыре варианта оформления

Программный генератор делает пиксельные `64×32` armor textures и инвентарные иконки для всех 20 предметов:

1. Factory — оливково-индустриальный базовый вариант.
2. Urban — серо-синий городской.
3. Arctic — светлый арктический.
4. NightOps — тёмный тактический.

Три дополнительных оформления доступны как `skin-packs/TechQuest_Hybrid_*.zip` после запуска генератора; это обычные Minecraft resource packs. Они меняют все гибриды сразу. Индивидуальное переключение на каждом предмете и исходная 3D-геометрия SBW пока **не реализованы**.

## Armor Trim / Smithing Templates

Генерируется `data/minecraft/tags/item/trimmable_armor.json`, поэтому новые гибридные шлемы и бронежилеты доступны для **ванильных Armor Trims** через кузнечный стол. Улучшение и узоры отделки — разные операции. Для новых гибридных предметов используется ванильный armor-рендерер, чтобы стандартные trim-слои могли отображаться. Модели исходных бронежилетов SBW, которые используют SimpleBedrockModel, отдельно не исправляются.

## Сборка и проверки

```bash
cd addons/hybrid-warfare-armor
python scripts/generate_assets.py
gradle build
```

Gradle скачивает NeoForge из Maven (требуется интернет). CI имеет отдельный `hybrid-armor-prototype.yml`. Обычным игрокам Python/Gradle **не требуются**: после успешной сборки JAR должен доставляться GUI-установщиком модпака, но сейчас установка **не подключена**.

**Не проверено запуском Minecraft.** Необходимые проверки: Gradle compile, существование donor ID у IC2 Nostalgia local.26, генерация рецептов, отображение armor trim, работа пластин SBW, Client → Main Menu, Dedicated Server → Done, вход игрока, перенос зачарований и баланс. До этого нельзя объединять с `main` и добавлять в публичный инсталлятор.

Визуальные концепты из переписки не являются настоящими скриншотами запущенной игры и могут отличаться от PNG-текстур этого прототипа.
