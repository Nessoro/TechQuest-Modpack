# TechQuest 0.3.3 — тест Physics Mod Lite

Общая ветка после объединения PR #11: **`feat/bosses-parcool-0.3.3-prep`**. Minecraft **1.21.1**, NeoForge **21.1.264**, Java **21**, единый Optimized-профиль. Это экспериментальный клиент с Physics Mod Lite **3.0.35** (`wudTG1nk`), а не проверенный игровой выпуск. Работа одиночной игры, которую подтвердил владелец на `535de72`, ещё не подтверждает этот эксперимент.

## Установка через GUI и официальный Launcher

1. Откройте [Actions этой ветки](https://github.com/Nessoro/TechQuest-Modpack/actions?query=branch%3Afeat%2Fbosses-parcool-0.3.3-prep). Выберите успешный **Build TechQuest alpha**, относящийся к последнему изменению состава/установщика этой ветки. Проверьте Windows EXE и Security Audit того же commit SHA.
2. Скачайте артефакт **TechQuest-Windows-GUI-Installer**, извлеките `TechQuestInstaller.exe`. Установите в **новую пустую папку**, например `TechQuest-Physics-Test`. Сохраните прежнюю рабочую установку для сравнения.
3. Используйте графическую установку Java 21 / NeoForge 21.1.264 и официальный Minecraft Launcher, как в [основной инструкции](INSTALL_0.3.3_PC_RU.md). В отдельной установке Launcher укажите новую папку игры. Python и консоль для установки клиента/запуска не нужны.
4. Сначала создайте новый тестовый мир. Существующий мир используйте только как отдельную резервную копию. Не добавляйте FBP, другие физические моды, AMW или новые gunpack одновременно: сначала нужно проверить единственное изменение.

Дополнительно доступен `.mrpack` из артефакта той же сборки. Physics Mod скачивается с оригинального Modrinth CDN с SHA512/SHA1-проверкой; его JAR не хранится в репозитории или EXE. На выделенный сервер мод не устанавливается.

## Настройки, которые устанавливаются автоматически

Настройки находятся в `config/physicsmod/` новой папки игры:

| Параметр | Стартовое значение |
| --- | --- |
| Physics Max Objects | 128 |
| Activation Distance | 16 блоков |
| Physics CPU Threads | 1 |
| Основной режим блоков | Blocky |
| Lifetime / Lifetime Variance | 2.0 / 0.0 |
| Дополнительная физика мобов, предметов, растительности, ткани, жидкостей, погоды и дыма | Выключена в соответствующих настройках |
| Собственное обрушение Physics Mod (`collapse`) | **Выключено**, включая одиночную игру |

Преднастройка ограничивает эксперимент визуальными блоками. У Incoming сохраняются его собственные обломки и подземные обрушения; урон, огонь и разрушение остальных установленных модов не перенастраиваются. Показ обычных серверных частиц блоков через физику включён, дополнительные ванильные частицы ломания выключены, чтобы сократить дублирование.

`physics_server_config.json` в **клиентской** папке нужен для встроенного сервера одиночного мира; это не инструкция поставить Physics Mod на выделенный сервер. GUI и Python-установщик сохраняют уже существующие конфиги, поэтому для воспроизводимого теста нужна новая папка. Не подменяйте свои настройки без резервной копии.

Ключи сверены с форматом чтения/записи **точного JAR 3.0.35**, а не угаданы по названиям полей. В `blockSettings` режим `Physics Type: 1` означает Blocky; в `mobSettings` значение `4` означает Off. Это порядковые номера перечислений конкретной версии, поэтому смена версии требует повторного изучения схемы. Автоматическая упаковка проверена отдельно; принятие настроек реальным клиентом и их влияние на FPS пока не проверены запуском Minecraft.

Перед созданием мира откройте **Physics Settings…** и проверьте значения. Если настройки не совпали или не читаются, не начинайте массовые взрывы: сохраните журнал и сообщите, какие значения показал GUI. Не включайте Collapse или дополнительные эффекты во время первого сравнения.

## Короткий игровой маршрут

Проверяйте по одному пункту, начиная с небольших разрушений. В контрольной рабочей установке и эксперименте используйте одинаковую сцену, позицию камеры, настройки графики и выделенную RAM; сначала дождитесь загрузки чанков. Начальные минимальные частицы Optimized оставлены прежними.

| Сцена | Что проверить |
| --- | --- |
| Главное меню → новый мир → сохранение и повторный вход | Нет вылетов; Physics Settings показывает преднастройку |
| Ломание нескольких каменных блоков и один TNT | Видны физические куски, они исчезают; частицы не накапливаются бесконечно |
| Статический механизм Create, затем движение небольшой конструкции | Нет ошибок рендера, пропавших блоков и вылетов; проверить Sodium в том же наборе |
| Оружие Superb Warfare и TaCZ, отдельно для каждого | Проверить взрывное оружие там, где оно действительно разрушает блоки; не требовать обломков от обычного попадания, не удалившего блок |
| Один обычный удар Incoming | Собственные обломки Incoming видны; нет чрезмерного дублирования, дополнительных повреждений и новых зависаний |
| Небольшой ядерный удар Incoming — последним | Оценить зависания, длительность формирования кратера и нагрузку; не считать отсутствие новых обломков доказательством поломки всей физики |

Массовое удаление блоков Incoming может обходить путь событий, который обрабатывает Physics Mod. Автоматическая интеграция каждого источника взрыва **не гарантирована**. При отсутствии нужного эффекта разбирать конкретный источник, а не добавлять сразу несколько физических модов.

Для отчёта достаточно указать commit SHA/сборку, CPU/GPU, системную и выделенную RAM, что удалось пройти из таблицы, FPS до/во время/после взрыва и длительность заметного зависания. Для TPS/MSPT можно дополнительно использовать Spark. При вылете приложить обезличенные `latest.log` и crash-report. Не объявлять серверную совместимость по одному одиночному сеансу.

Для отката выберите в Launcher прежнюю рабочую установку с прежней папкой игры. Модификации тестового мира автоматически в неё не переносятся.
