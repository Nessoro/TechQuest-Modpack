# Project MMO 2.10.47 — настройки интерфейса TechQuest

В TechQuest `0.3.3-alpha` установлен Project MMO `2.10.47` (`pmmo-1.21.1-2.10.47.jar`). Лишние надписи `Endurance`, `Woodcutting`, `Excavation`, `Combat`, `Mining`, `Agility`, `Building` рисует **Project MMO**, а не Incoming или Xaero.

## Выбранные стартовые настройки

Для **новой** установки клиент получает `config/pmmo-client.toml`:

```toml
[Client.GUI]
"Display Skill List" = false
"Skill List Use Icons" = true
"Skill List Xoffset" = 0.70
"Skill List Yoffset" = 0.05
"Display Gain List" = true
```

- **Список навыков выключен** при первом запуске, поэтому не заслоняет миникарту и игровую сцену.
- Клавиша **Left Alt** переключает видимость списка. Точное назначение можно проверить и изменить в «Настройки → Управление → Project MMO».
- При включении используются **иконки** вместо длинных названий и положение в правой части экрана. На узком экране при необходимости уменьшите Xoffset.
- Отдельный список опыта (`Display Gain List`) остаётся включён.
- Сам мод, прокачка, навыки и бонусы остаются включены. Мы меняем только отображение.
- В моде нет отдельного параметра масштаба шрифта этого списка; общий GUI Scale Minecraft влияет и на другие элементы.

## Если TechQuest уже установлен

Ни Windows Installer, ни Python bootstrap **не заменяют** существующий файл `config/pmmo-client.toml`. Это защищает пользовательские настройки. Можно нажать **Left Alt**, чтобы сразу скрыть список в текущей игре; либо при закрытой игре вручную изменить перечисленные значения в существующем файле.

Новый пресет применяется только в **чистой папке установки** после сборки и использования обновлённого установщика. Не нужно удалять сохранения и персонажей, чтобы скрыть HUD.

## Где используется пресет

- Генератор `build_pack.py`: `client_config_overrides` → `.mrpack` и `output/client`.
- Установщик Windows: разрешён безопасный путь `config/pmmo-client.toml`; self-test проверяет значения и сохранность пользовательского файла.
- Python-установщик клиента: импортирует пресет, не перезаписывает прежний файл.
- На выделенный сервер клиентский `pmmo-client.toml` не устанавливается.

Исходный код Project MMO: https://github.com/Caltinor/Project-MMO-2.0/blob/main/src/main/java/harmonised/pmmo/config/Config.java
