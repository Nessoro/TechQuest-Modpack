# HP и более короткая контузия

Проверено по оригинальным JAR, совпавшим с SHA из modlist.json:

- Health Indicator TXF 1.3.12 (`xGqsX1go`), встроенный ConfigLib TXF 2.0.4: файл `config/healthindicatortxf.json5`, поля ModConfig; BOTH — текущее/максимальное HP, TOP_CENTER и yValue 36 — отдельно от стандартной миникарты слева. Мод не удалялся. На присланном скриншоте видны два интерфейса, а не отсутствие JAR.
- Jade 15.10.6 (`eYz2YBGT`): `config/jade/plugins.json` использует вложенные namespace, например `minecraft → entity_health`, а не плоский ключ с двоеточием. Отключено только дублирование HP/брони; подсказки остаются.
- Explosion Overhaul 0.2.3.0 (`mxfQE01f`): `config/explosionoverhaul/explosionoverhaul-client.toml`, `[Concussion] concussionDurationMultiplier = 0.25` вместо 1.0. Эффект сохраняется, длительность умножается на четверть. Это не изменение урона, шанса контузии или разрушений.
- Incoming 3.10.4 (SHA-256 закреплён): `config/incoming-client.toml → screen_effects = 0.35`, `camera_shake = 0.35` вместо 1.0. Это интенсивность экранной контузии и тряски, не длительность и не серверный урон. По уточнению владельца уменьшаются оба эффекта, включая звук: длительное повреждение слуха Incoming (`nuke_tinnitus`) выключено. У него есть только переключатель, не множитель времени; короткие слуховые эффекты Explosion Overhaul и обычные звуки/акустическое приглушение Incoming сохранены.

Версии Modrinth, имена файлов и хеши не меняются. При смене закреплённых версий схема преднастроек требует пересмотра. Config-файлы доставляются клиенту одинаково через mrpack, Python bootstrap и GUI; на выделенный сервер не устанавливаются. Существующие пользовательские файлы не перезаписываются. Для оценки нужна новая папка либо ручная настройка прежнего профиля.

Настоящий клиентский CI проверяет загрузку этих значений из классов модов до меню. Расположение при разных GUI Scale, несколько boss bar, бой, слух и взрывы в мире требуют игрового теста; один запуск меню их не подтверждает.

## Камера Incoming

В оригинальном `ua.zentix.incoming.client.Keys` CAMERA = GLFW 78, то есть **N** (`key.incoming.camera`, «Камера снаряда»). `ProjectileCamera.cycle` переключает отслеживаемые снаряды игрока; если список пуст, выводится «Нет снарядов в полёте». Подсказка самого мода: N — следующий, Shift — выход, F5 — вид. ЛКМ может переназначать цель. Автовключение — отдельный `auto_camera`, по умолчанию false; не включаем его принудительно.
