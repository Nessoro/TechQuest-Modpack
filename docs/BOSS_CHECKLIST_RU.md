# TechQuest: общий чек-лист боссов Legendary Monsters

**Статус:** реализация для игрового тестирования в отдельной ветке; не является подтверждённым релизом.

Совместимость: Minecraft Java **1.21.1**, NeoForge **21.1.264**, Legendary Monsters **2.2.4**, Open Loader (оба профиля, клиент и сервер).

## Как пользоваться

1. Установите TechQuest из сборки, содержащей эту ветку. Больше ничего вручную ставить не требуется: сборщик размещает `config/openloader/packs/techquest_boss_checklist.zip` и на клиенте, и на сервере.
2. Зайдите в обычный мир или на сервер с друзьями. Откройте **Достижения** (по умолчанию клавиша **L**, либо меню паузы).
3. Откройте отдельную вкладку **«TechQuest: охота на боссов»**. В ней три ветки: **Верхний мир**, **Незер**, **Энд**. Непобеждённые противники серые, победы выделены цветом.
4. Если хотя бы один игрок убил противника с зачётом убийства игроку, достижение автоматически засчитывается **всем подключённым игрокам** примерно в течение секунды. Игрок, подключившийся позже, тоже получит отметку.
5. После выхода, перезагрузки сервера или смерти персонажа общий прогресс сохраняется **в данных мира** (scoreboard), а не только на клиенте.

### Кого отслеживает первая версия

**Верхний мир (6):** Ancient Guardian, Overgrown Colossus, Cloud Golem / Cumulonimbus, Dune Sentinel, Frostbitten Golem, Possessed Paladin / Orion.

**Незер (4):** Skeletosaurus, Lava Eater, Warped Fungussus, Withered Abomination.

**Энд (4):** Chorusent (registry ID: `endersent`), Shulker Mimic (мини-босс), Annihilation Pursuer (мини-босс), The Obliterator.

Итого: **14 противников**, включая двух мини-боссов. ID взяты из официального реестра `Miauczel/Legendary-Monsters-1.21.1-NeoForge/src/main/java/net/miauczel/legendary_monsters/entity/ModEntities.java`. Ошибочное оригинальное написание `posessed_paladin` сохранено намеренно.

## Правила синхронизации

- Одна отметка на каждого уникального противника, **не счётчик повторных убийств**.
- Убийство засчитывается при событии `minecraft:player_killed_entity` — когда Minecraft считает его убийством игрока. Смерть монстра от механизмов, падения или других мобов без зачёта игроку не отмечается.
- Прогресс общий **в рамках одного мира/сервера**, не между разными мирами и серверами. Не зависит от близости игроков или принадлежности к команде.
- Новое сохранение прогресса действует **только на убийства после установки**. Надёжно восстановить старые победы из прошлого автоматически через датапак нельзя.
- Для вручную подтверждённой старой победы администратор может выполнить, например, `/function techquest_bosses:kill/frostbitten_golem`. Затем общий прогресс синхронизируется сам.
- Не удаляйте datapack из текущего мира, не сохранив резервную копию. Без него вкладка пропадёт; данные мира сохраняются отдельно, но поведение при повторной установке нужно проверять.
- Никаких сторонних JAR или дополнительных разрешений игрокам не требуется.

## Проверка перед слиянием

- [ ] `python -m unittest discover -s tests -p "test_boss_checklist.py"`
- [ ] Сборка `.mrpack` и GUI-клиента действительно содержит ZIP в `config/openloader/packs/`.
- [ ] Загрузить отдельный новый мир и убедиться, что вкладка появится без ошибок в `latest.log`.
- [ ] Убить одного босса в одиночной игре. Достижение получено, после перезахода сохраняется.
- [ ] Два игрока на выделенном сервере: игрок A убивает босса, игрок B получает отметку не позже следующей секунды.
- [ ] Игрок B выходит перед убийством, возвращается позже и получает отметку.
- [ ] Проверить kill credit для специальных смертей (оружие Superb Warfare, магия, отражённые атаки): отсутствие зачёта игроку означает отсутствие отметки.
- [ ] Миры с разными сохранениями не смешивают прогресс.
- [ ] Сделать резервную копию мира перед обновлением; на существующем мире проверить появление новой вкладки.

**Непроверено:** реальный игровой запуск с полным набором модов и выделенным сервером. Чисто статические тесты ZIP не подтверждают работу внутри Minecraft.

## Реализация

Генератор: `scripts/boss_checklist.py`. Сборщик подключает ZIP через `scripts/guide_assets.py` и автоматически распространяет его среди клиентов и серверов с Open Loader. В датапаке используются только стандартные достижения, функции и scoreboard Minecraft 1.21.1, чтобы не добавлять отдельный интерфейсный мод и не менять управление.

Это первая итерация именно для **Legendary Monsters**. Боссы Cataclysm, Bosses of Mass Destruction и других модов могут быть добавлены отдельным изменением после проверки их реестров.
