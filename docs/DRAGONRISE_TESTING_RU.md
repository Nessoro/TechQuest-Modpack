# DragonRise: Reforge 1.5.1 — экспериментальный импорт

Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21. Официальный файл: [CurseForge #9208025](https://www.curseforge.com/minecraft/mc-mods/sbw-drr/files/9208025), project 1346094. Лицензия на странице проекта — GPLv3. Сам JAR не включается в репозиторий или публичный .mrpack. Достоверная контрольная сумма пока не закреплена.

## Установка
1. Сделайте резервную копию мира. Используйте отдельный тестовый профиль TechQuest.
2. Скачайте оригинальный dragonrise_reforge-1.5.1-release.jar с указанной страницы (именно NeoForge 1.21.1).
3. В тестовом Windows Installer укажите папку TechQuest и нажмите «4. Добавить DragonRise». Установщик проверяет имя, наличие Superb Warfare и структуру JAR, не подтверждая подлинность. Локальный SHA-256 сохраняется в TECHQUEST_DRAGONRISE_IMPORT.txt.
4. На остановленный выделенный тестовый сервер скопируйте тот же JAR в mods. Сравните SHA-256 клиента и сервера. После обновления TechQuest повторите импорт, если дополнительные JAR были перемещены в резервную папку.

## Приёмка (не выполнена)
- Запустить клиент и dedicated server с SBW 0.8.9.2 и DragonRise; проверить log, crash reports, отсутствие ошибок регистрации, dependency и mixin.
- Проверить наличие Rafale в творческом инвентаре, спавн, посадку/взлёт, управление, сохранение и повторную загрузку сущностей.
- В отдельном мире повторить с Incoming 3.10.4 и затем с опциональным AMW; проверить конфликты клавиш, сетевую синхронизацию и поведение техники. Не переносить в основной мир до успешной проверки.
- Измерить FPS, TPS/MSPT и память относительно того же мира без DragonRise. Проверить мультиплеер с двумя клиентами, переподключение, сохранение и рестарт сервера.
- При сбое убрать JAR с клиента и сервера на остановленном сервере; восстановить копию мира без добавленных сущностей.

Проверка метаданных и сборка EXE не заменяют игровой тест. Не объявлять стабильный релиз до результатов; версию следующего релиза согласовать с открытыми PR.
