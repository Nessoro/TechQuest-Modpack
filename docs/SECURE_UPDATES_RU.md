# TechQuest: защищённые обновления и сохранность данных (Windows 10/11)

## Границы доверия и лицензия

TechQuest устанавливает моды для **официального Minecraft Launcher**, Minecraft Java Edition 1.21.1 (приобретённой пользователем) и NeoForge 21.1.264. Пользователь сам входит в Microsoft через официальный Launcher; установщик не реализует аутентификацию, не предлагает пиратский Minecraft и не обходит проверку лицензии.

Установщик **не читает** браузерные профили, cookies, пароли, токены Microsoft/GitHub, документы, миры, инвентари и личные файлы. Он не передаёт телеметрию. GitHub и CDN получают IP-адрес и обычные метаданные HTTPS-запросов; анонимность не обещается.

Важно: Java-моды выполняются с правами пользователя Minecraft. Подпись обновления и проверки SHA доказывают соответствие утверждённым файлам, **но не гарантируют безвредность стороннего JAR**. Сохраняйте аудит источников и зависимостей, ограничения Windows Defender и ручные тесты.

## Механизм обновлений

1. При запуске EXE проверяет публичные GitHub Releases без авторизации, токенов и cookies (при необходимости есть ручная проверка).
2. Доверенный релиз должен содержать строго четыре файла: techquest-release.json, techquest-release.sig, TechQuest_Optimized.mrpack, TechQuestInstaller.exe.
3. JSON содержит фиксированные repository/tag, идентификатор версии и SHA-256 двух артефактов. Точные байты JSON подписаны RSA-3072/SHA-256, проверка выполняется по **публичному ключу внутри EXE**. Самостоятельные SHA-файлы из того же репозитория без подписи ненадёжны.
4. Дополнительно проверяются ограничения для Minecraft 1.21.1 / NeoForge 21.1.264, HTTPS-хосты, имена JAR, размеры и SHA-512 загружаемых модов. Недоверенные URL и подписи отклоняются.
5. Обновление осуществляется только по нажатию пользователя. Скачиваются **только изменившиеся управляемые JAR**, до замены сохраняются оригиналы и журнал восстановления. Посторонние JAR не удаляются.
6. Кнопка отката возвращает предыдущий набор управляемых модов. При обрыве операции журнал позволяет восстановить предыдущую версию на следующем запуске. Новый EXE можно скачать после проверки подписи, но он **не запускается автоматически**.

Каталоги saves, config, screenshots, resourcepacks, logs, файл options.txt, пользовательские JAR и любые сведения об учётных записях не меняются. Для безопасного обновления нужен профиль с .techquest/state.json, созданный обновлённым EXE; для старой неуправляемой установки используйте новую отдельную папку.

## Публикация релиза — только владелец проекта

**Закрытый ключ не должен попадать в GitHub, GitHub Actions, код, Issue/PR, облачный CI, логи или к игрокам.** Храните его зашифрованным офлайн и делайте защищённую резервную копию. В коде расположен *только* публичный ключ: windows-installer/assets/update-public-key.pem.

После успешных сборки, безопасности и тестов создайте подписанный комплект на доверенном локальном ПК (Python 3 и OpenSSL нужны **только владельцу**, не игрокам). Пример команды:

    python scripts/sign_release.py --tag v0.3.3-micro3-preview --pack output/TechQuest_1.21.1_0.3.3_ALPHA.mrpack --installer dist/TechQuestInstaller.exe --private-key /secure/offline/TechQuest_release_signing_PRIVATE.pem --out /secure/signed-release

Загрузите ровно четыре файла из указанного выходного каталога в GitHub Release с таким же тегом. Публикация подписей **не выполняется CI**, чтобы репозиторий или скомпрометированный workflow не получил закрытый ключ.

Прежние релизы, включая v0.3.3-micro2-preview, ещё не содержат такую подпись и намеренно игнорируются обновляющим механизмом. Коммиты ветки main не обновляют компьютеры игроков автоматически.

Если закрытый ключ украден, немедленно приостановите выпуски, смените ключ, пересоберите EXE со **встроенным новым публичным ключом** и доставьте его игрокам по доверенному каналу. Обновление публичного ключа в репозитории не меняет уже выданные EXE.

## Предупреждения и тесты

- RSA-подпись обновления — **не** Windows Authenticode; для SmartScreen и подлинности издателя нужен дополнительный сертификат подписи EXE.
- Откат JAR **не** откатывает сохранения миров, изменённых после запуска новой версии. Перед переходом на новые версии сделайте копию saves.
- Бэкапы управляемых модов остаются локально в .techquest/backups; не удаляйте каталог, используемый активным rollback.json.
- Нельзя утверждать, что SHA или ClamAV гарантируют отсутствие шпионского кода внутри модов.
- Изолированные тесты: dotnet run --project tests/updater/UpdaterTests.csproj --configuration Release
- Полный тест: python -m unittest discover -s tests -v
- До подтверждения настоящего запуска клиента статус сборки: **не проверено запуском Minecraft**.

## Новое окно TechQuest Launcher

В окне есть разделы «Ваша сборка», «Установка и загрузки», «Обновления» и «Инструменты». Наличие подписанных релизов проверяется при старте без чтения учётных данных. Тестовые (preview) релизы отключены по умолчанию.

**Повторная установка в ту же папку:** лаунчер теперь различает пустую папку, управляемую установку TechQuest и прежнюю установку без файла состояния. Для управляемой сборки основная кнопка **проверяет контрольные суммы**, а не скачивает всё заново. Для старой установки кнопка «Подключить сборку» сверяет **все ожидаемые JAR по SHA-512** из встроенного манифеста: при совпадении записывается состояние и включаются будущие обновления. При несовпадении моды не меняются, смешивать сборки не предлагается.

**«Восстановить отсутствующие»** предназначено только для управляемой установки, полностью соответствующей встроенному манифесту. Все отсутствующие JAR загружаются и проверяются до перемещения в папку игры; изменённые существующие файлы не удаляются и не заменяются без дополнительного разбора. Это предотвращает случайную порчу пользовательских модов. Если на ПК установлена другая версия, используйте проверенные подписанные обновления, а не встроенный пакет.

Кнопка «Открыть Minecraft Launcher» запускает обнаруженный официальный Windows Launcher либо показывает инструкцию по ручному запуску. Никакой собственной авторизации Microsoft, обхода лицензии или отдельного игрового загрузчика Java не добавлено.
