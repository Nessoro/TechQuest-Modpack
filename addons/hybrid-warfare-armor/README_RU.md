# TechQuest Hybrid Warfare Armor — прототип для NeoForge 1.21.1

**Текущий статус:** компиляция JAR, Python-тесты генератора и проверка ресурсов в GitHub Actions пройдены. **Не проверено запуском Minecraft.** Изменения хранятся только в draft PR #51 и не включены в стабильную сборку TechQuest.

## Tactical Blue V2 — новый игровой внешний вид

V2 переделывает первоначальные 2D/плоские военные текстуры в полноценную многослойную чёрно-синюю 3D-броню с синей технологической подсветкой. Новый игровой вид соответствует предпросмотру, созданному из фактической модели и фактических игровых UV-текстур (предпросмотр не является скриншотом Minecraft).

**Четыре предмета:**
- `techquest_hybrid:mek_ru_helmet_6b47` — шлем по мотивам 6Б47 из Superb Warfare, с объёмными боковыми панелями, креплением сенсора, рельсами и открытой лицевой частью;
- `techquest_hybrid:mek_ru_chest_6b43` — гибрид бронежилета 6Б43 и Mekanism с керамической плитой, 3×3 энергопанелью, тремя подсумками и рюкзаком-батареей;
- `techquest_hybrid:mek_ru_leggings` — новые технологические поножи TechQuest (Superb Warfare не содержит поножей);
- `techquest_hybrid:mek_ru_boots` — новые технологические ботинки TechQuest (Superb Warfare не содержит ботинок).

В оригинальном Superb Warfare нет полного четырёхчастного набора 6Б43/6Б47. Поэтому новые штаны и ботинки — **самостоятельные предметы аддона, а не перенесённые предметы Superb Warfare**. Все 4 предмета используют стандартную гуманоидную анимацию головы, корпуса, рук и ног. Синяя подсветка в текстурах декоративная — она не создаёт реального источника света в игре.

**Исходные файлы реализации:**
- `src/main/java/dev/techquest/hybrid/client/MekMilitaryArmorModel.java` — 3D-модель из оригинальных кубов, загружаемых из `.cuboids`;
- `src/main/java/dev/techquest/hybrid/client/MekMilitaryArmorClient.java` — регистрация четырёх моделей для клиента;
- `scripts/tactical_v2.py` и `scripts/tactical_blue_v2.b85` — детерминированная генерация четырёх 256×256 UV-атласов и текстовых моделей;
- `scripts/generate_assets.py` — иконки, рецепты и теги брони;
- `scripts/test_tactical_v2.py` — проверка геометрии, исходников и структуры PNG.

**Рецепты:** шлем 6Б47/бронежилет 6Б43 из Superb Warfare + соответствующие предметы MekaSuit + Netherite Upgrade Template через кузнечный стол. Новые поножи/ботинки: незеритовый предмет того же слота + соответствующая часть MekaSuit + Netherite Upgrade Template. Рецепты прототипные; технические доноры расходуются **без переноса энергии и модулей**. Не рекомендуется создавать их в основном мире до тестирования.

## Другие комбинации и скины

Кроме Tactical Blue V2, в прототипе зарегистрированы 20 базовых комбинаций из четырёх технических направлений (IC2 Nostalgia, Modern Industrialization, Mekanism, Oritech) × пяти исходных шлемов и жилетов Superb Warfare. Эти 20 базовых предметов имеют процедурные оригинальные текстуры и могут переключаться между Factory, Urban, Arctic, NightOps с помощью ресурспаков.

**Только 4 предмета Tactical Blue V2 получили новую объёмную геометрию.** Не следует представлять остальные 18 предметов в качестве уже готовой 3D-экипировки. Мод не использует оригинальные модели и картинки авторов Superb Warfare — новые текстуры и кубическая геометрия нарисованы для TechQuest.

## Ванильные Armor Trims / smithing template

Генератор регистрирует все 22 гибридных предмета в теге `minecraft:trimmable_armor`, а также соответствующих тегах `head_armor`, `chest_armor`, `leg_armor`, `foot_armor`. Это позволяет использовать ванильные кузнечные шаблоны отделки.

**Отображение рисунков Armor Trim на дополнительных выступающих 3D-пластинах пока не проверено** и может потребовать отдельного текстурного слоя/UV-сопоставления. Добавление тега само по себе не гарантирует корректный trim-рендер на такой модели.

## Установка и тестирование

Для разработчика:

```bash
cd addons/hybrid-warfare-armor
python scripts/generate_assets.py
python -m unittest discover -s scripts -p 'test_*.py' -v
gradle build
```

В GitHub Actions JAR находится внутри артефакта `techquest-hybrid-prototype` workflow `Build hybrid armor addon (prototype)`. Для ручного тестирования необходимо:

1. Использовать отдельный тестовый профиль Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21;
2. Подключить **те же закреплённые версии Superb Warfare и Mekanism**, что используются в TechQuest;
3. Положить JAR в тестовую директорию `mods` на клиенте и сервере;
4. Проверить клиентский рендер, шлем при поворотах головы, сгибание рук и ног, приседание, отображение зачарований и Armor Trims, поведение баллистических пластин, сохранение мира и вход на сервер.

Не добавлять JAR в Windows GUI installer и `modlist.json` до реального прохождения тестов в Minecraft. CI-компиляция не означает, что комплект корректно выглядит при всех анимациях и работает в мультиплеере.
