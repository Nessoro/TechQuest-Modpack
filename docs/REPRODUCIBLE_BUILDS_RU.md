# Закреплённый состав 0.3.3

`modlist.json → modrinth_lock` фиксирует 92 уже выбранных проекта Modrinth, включая транзитивные зависимости: canonical project ID, точный version ID, имя JAR, SHA-512 и стороны установки. За основу взяты фактические файлы собранного `.mrpack`; до фиксации их хеши были сверены с оригиналами Modrinth. IC2/Incoming по-прежнему проверяются собственными закреплёнными URL/хешами. Собственный data-only TechQuest Compatibility собирается из исходников.

Это предотвращает незаметное обновление состава при повторном CI. Одна и та же версия также не может подменить закреплённый файл. Проверки включают:

- другой обязательный version ID, отсутствующий/изменённый JAR или новые незакреплённые зависимости — ошибка;
- изменение клиентской/серверной стороны после штатных reviewed overrides — ошибка;
- отсутствие любой записи закреплённого профиля — ошибка, включая прежние optional позиции: готовый Optimized не должен незаметно терять моды;
- аудитор доступности проверяет именно закреплённую версию и файл, а не последний релиз.

Это фиксация версий/файлов, не доказательство игровой совместимости. Лицензии и источники авторов сохраняются; JAR в Git не добавляются. Замораживание всех файлов не заменяет будущий явный пересмотр зависимостей и обновлений безопасности.

Обновление для разработчика: выбрать официальный релиз Minecraft 1.21.1 / NeoForge, проверить файл, лицензию и зависимости; согласованно изменить корневую запись и соответствующие записи lock. Повторить полную сборку, аудит, Windows EXE/Security и реальный клиентский smoke. Для удаления/добавления компонента пересмотреть весь граф; при несовпадении данных сборка должна отказать. Обычному игроку редактирование lock, Python и консоль не нужны.

При завершении #5 дополнительно исправлен `options.txt`: для 1.21.1 нужен `version:3955`. Без него Minecraft запускает старую миграцию числовых клавиш на современных `key.keyboard.*`, пишет `NumberFormatException` и не загружает профиль. Заголовок создаётся единым `client_options` для GUI/mrpack/bootstrap. Существующие пользовательские файлы по-прежнему сохраняются; для исправленных стартовых настроек используйте новую папку либо настройте прежний профиль через меню игры.

CI проверяет DataVersion по `version.json` внутри оригинального SHA-проверенного клиента. Временный наблюдатель проверяет настоящий TitleScreen без загрузочного overlay, фактические Fast/6/5/60 и назначения из key_defaults. Наблюдатель не входит в модпак; первый экран Accessibility пропускается предпочтением только в CI-копии. Тест не входит в мир, не принимает EULA и не запускает сервер.
