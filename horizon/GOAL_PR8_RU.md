- Ветка `experiment/horizon-port-lab`, PR #8 остаётся draft до игровых доказательств.
- Основной NeoForge main сохраняется. Не возвращать исключённые MCHeli/TaCZ/ParCool.
- Не публиковать релизы/среду, не объединять PR и не отправлять изменения
  в удалённый репозиторий без отдельного разрешения владельца.
- Minecraft EULA для изолированного теста уже принята. Миры и игровые файлы
  только в отдельных каталогах, сервер только loopback, online-mode и whitelist.
- Не выдавать импорт JSON за исполнение Java, успешный SDK — за игровой порт,
  отсутствие ошибки в журнале — за проверенный мультиплеер.
- Не коммитить игровые JAR/ресурсы, сторонние hmod/datapack, миры, токены или логи.
