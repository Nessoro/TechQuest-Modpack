# TechQuest 0.3.3-micro2 — собственный RPG Core вместо Project MMO

**Версия:** предварительный микропатч TechQuest 0.3.3, Minecraft Java 1.21.1, NeoForge 21.1.264, Java 21. Основан на [micro1](MICROPATCH_0.3.3_RU.md), а не на старой сборке main. Основные технологии, магия, путешествия, механизмы, FTB Ultimine, Sophisticated Storage и синхронизация Apotheosis World Tier сохранены.

## Что исправлено

По результату игрового теста владелец подтвердил, что Project MMO вызывал нежелательное разрушение блоков над разрушаемым. Поэтому **Project MMO удалён полностью** (его JAR больше не входит в новый список модов). Мы не изменяем чужой бинарник и не продолжаем патчить PMMO Vein Mining.

Вместо него разработан **TechQuest RPG Core 0.1.0** — самостоятельный оригинальный мод на стандартном загрузчике NeoForge `lowcodefml`. Код мода и исходные datapack-функции лежат в `rpg-core/` репозитория. Никаких заимствованных классов PMMO или собственного массового разрушения блоков в нём нет. Он устанавливается на клиента и выделенный сервер в составе той же единой сборки.

**Это не полная функциональная копия PMMO:** его числовые уровни, навыки/XP, требование уровней для предметов, Extra/Treasure Drops, командный XP, Salvaging, Vein Mining и HUD отключены **путём удаления PMMO**. Перенос уровней PMMO в новый мод не предусмотрен. Старый PMMO конфиг/опыт могут сохраниться в мире/папке, но новое ядро их не читает.

### Бонусы и сложность вместо уровней XP

| Триггер | Результат |
| --- | --- |
| Достижение «Железные инструменты» | Haste I |
| Достижение «Огненный стержень» | Resistance I |
| Достижение «Победа над драконом» | Speed I |
| Дни мира 7–20 | Обычные враждебные мобы: Strength I |
| Дни мира 21–41 | Strength I + Resistance I |
| Дни мира 42+ | Strength II + Resistance I |

Эффекты обновляются раз в 100 тиков (около 5 секунд), работают в обычном мире, Незере и Энде; члены vanilla-тега hostile перечислены явно. Боссы и модовые мобы изначально не меняются. Haste ускоряет обычную добычу, **но сам не вызывает уничтожение соседних блоков**. Эти правила могут позже балансироваться после игровых испытаний. **Это замена уровней на игровые этапы**, а не отключение XP с сохранением старой PMMO-модели.

Администратор сервера может отключить ядро, только бонусы или только мобов без удаления JAR:

```mcfunction
/scoreboard players set #enabled tqrpg_flags 0
/scoreboard players set #perks tqrpg_flags 0
/scoreboard players set #mobs tqrpg_flags 0
```

Для включения вернуть значения `1`. Данные флагов хранятся в scoreboard мира. Эти команды не изменяют другие RPG-моды.

## Как обновиться без новых папок

1. **Закройте Minecraft и остановите сервер.** Сделайте отдельную копию мира, `mods`, `config`, `defaultconfigs` и серверных данных.
2. После прохождения CI откройте [предрелиз micro2](https://github.com/Nessoro/TechQuest-Modpack/releases/tag/v0.3.3-micro2-preview). Скачайте `TechQuestInstaller.exe` из Assets **без входа в GitHub**. Если релиз ещё не опубликован, использовать старый micro1 EXE для обновления до micro2 нельзя.
3. Запустите GUI установщика. Укажите **существующую папку игры TechQuest**, где уже стоит старая сборка. Не выбирайте общую `.minecraft`.
4. Выберите «Установить / обновить». Установщик скачает новые/изменённые JAR (до пяти параллельно), проверит хеши и размер, затем **заменит только каталог `mods`**. Неизменившиеся JAR берутся из локального хранилища при совпадении хешей. Старый каталог `mods` сохранится как **одна** `.techquest-previous-mods`. На следующем обновлении эта резервная папка будет перезаписана; отдельный бэкап мира лучше хранить вне папки игры.
5. `saves`, `config`, `options.txt`, `defaultconfigs`, данные карт и установленный профиль Launcher не меняются. NeoForge переустанавливать не требуется, если используется **21.1.264**.
6. В новом `mods` должны быть `techquest-rpg-core-0.1.0.jar` и `ftb-ultimine-neoforge-2101.1.15.jar`, **не должно быть** `pmmo-*.jar`.
7. Если ранее был создан `config/pmmo-client.toml` или старый `config/openloader/packs/techquest_micropatch_033.zip`, установщик **не удаляет** пользовательские файлы. Не меняйте их без резервной копии; после удаления PMMO первый файл им не используется. Старый микропатч-датапак может оставаться источником World Tier, и он также не перезаписывается.
8. Запустите текущий профиль NeoForge. На копии тестового мира сломайте нижний блок вертикального столба из трёх каменных блоков **без** удержания клавиши Ultimine: должен сломаться один блок. Проверьте работу FTB Ultimine только при сознательном использовании клавиши. Проверьте достижения и этапы усиления мобов.
9. Для мультиплеера нужен одинаковый набор на клиенте и сервере. Проверка серверного совместного World Tier на нескольких игроках всё ещё обязательна.

### Откат

Если после обновления TechQuest перестал запускаться, **закройте игру**, сохраните логи и верните прежние JAR из `.techquest-previous-mods` в `mods` (лучше сначала переименовать неисправный `mods`). Старый набор не станет совместим с игровым прогрессом, записанным новым модом, автоматически: при необходимости восстановите резервную копию мира. Проверяйте, что наборы модов клиента и сервера совпадают.

## Публикация и условия выпуска

- История разработки: [PR #25 — micro1](https://github.com/Nessoro/TechQuest-Modpack/pull/25) → отдельный PR micro2. Слияние в main не требуется для изолированного предрелиза, но CI обязателен.
- Код выполняет **модульные/статические проверки**, сборку *.mrpack*, реальную сборку Windows GUI, проверку JAR и ClamAV. После успешного полного CI выпускается отдельный публичный **`v0.3.3-micro2-preview`**, отдельный от micro1.
- **Нельзя считать подтверждёнными**, пока не протестировано на ПК: работа достижений/баффов в мире, эффекты на мобов, серверная синхронизация World Tier и отсутствие побочных конфликтов с Apotheosis/FTB Ultimine. Это тестовый патч, **не стабильный релиз**.
