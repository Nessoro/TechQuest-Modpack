# Управление, Xbox/джойстик и зум — задачи #13 и #18

Тестовая ветка **`fix/neoforge-zoom-controls-0.3.3`** продолжает Optimized 0.3.3 на Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21. Это один клиентский профиль. Новые моды управления и конфиги **не проверены запуском Minecraft**; успешная игра на базе `535de72` на них не распространяется.

## Новая установка и зум

Скачайте `TechQuest-Windows-GUI-Installer` из успешного [Actions этой ветки](https://github.com/Nessoro/TechQuest-Modpack/actions?query=branch%3Afix%2Fneoforge-zoom-controls-0.3.3), извлеките EXE и установите в новую папку. Python и консоль не нужны. Дальнейшие шаги официального Launcher: [установка NeoForge](NEOFORGE_FALLBACK_RU.md).

| Действие на новой установке | Назначение |
| --- | --- |
| Плавный зум Better Zoom | **Удерживать Z** |
| Приближение / отдаление | Колёсико вверх / вниз при удержании Z |
| Возврат обычного FOV | Отпустить Z |
| TaCZ: настройка оружия | **F8** вместо Z |
| Xaero: увеличение миникарты | **F9** вместо Z |
| Sophisticated Backpacks: первое улучшение | **F10** вместо Alt+Z |
| Настройки зума | Моды → Better Zoom → Config |

Без активного зума колесо сохраняет обычное переключение предметов. В выбранном `betterzoom-client.toml`: режим `WHEEL`, плавный переход, шаг 2, удерживание клавиши, HUD и рука видимы, звук зума выключен. Дополнительные клавиши Better Zoom для настройки/плюса/минуса по умолчанию не назначены, чтобы не занимать C / Alt+C и цифровую клавиатуру. Их можно назначить в меню управления. Пределы FOV определяются реализацией Better Zoom (от 1 до обычного FOV); отдельного выдуманного параметра минимума/максимума в конфиге нет.

Клавиша Z переназначается стандартным способом. Общий `options.txt` для Windows GUI, `.mrpack` и developer bootstrap создаётся из одного источника. GUI и Python bootstrap **сохраняют существующий options.txt и конфиг зума**, поэтому при обновлении прежней папки пользовательские назначения остаются: проверьте Z/F8/F9 вручную либо используйте новую папку для воспроизводимого теста.

## Поиск конфликтов

Добавлен **Controlling** с библиотекой **Searchables**: поиск действий, фильтр конфликтующих назначений и просмотр свободных клавиш в меню управления. Наличие одинаковой клавиши само по себе не доказывает двойное действие — важны контекст, модификаторы и состояние игрока.

В артефакте сборки доступны `keybindings-audit.json` и `keybindings-audit.md`. Разработческий анализатор читает конструкторы KeyMapping внутри проверенных JAR, включая вложенные библиотеки, и применяет стартовые назначения профиля. Он не запускает чужой код. CI проверяет, что среди распознанных назначений Z остаётся у Better Zoom; старые действия TaCZ/Xaero переезжают на F8/F9, улучшение рюкзака Alt+Z — на F10 без модификатора. Для разборщика вычисляемых имён закреплена текущая версия Sophisticated Backpacks: изменение выпуска требует повторной проверки. Неразобранные конструкторы сохраняются в отчёте как **unresolved**, а не выдаются за отсутствие конфликта.

**Оставшиеся области проверки #13:** R (оружие / ParCool / способности брони), C (ползание и дополнительные действия), G/H/V/B и другие группы из отчёта. Они требуют разбора состояния игрока в игре перед общей перенастройкой. В этой итерации автоматически изменены только назначения, необходимые для Z; вся остальная рабочая схема сохранена. Это не обещание полного отсутствия конфликтов во всём наборе.

Forgematica/MaFgLib имеют также собственную систему сочетаний и экран настроек; стандартный KeyMapping-аудит и Controlling покрывают её не полностью. Проверьте открытие меню схем, выбор/вставку и сочетания с M отдельно.

## Xbox и джойстик

Для указанного владельцем Xbox/джойстика включён **Controlify 3.0.1 LTS** с **YACL 3.8.2**. Поставляются только клиентские JAR. В проверенном оригинальном Controlify присутствует SDL3 для Windows x64; отдельная ручная установка Python, консольных утилит или SDL не нужна.

1. Подключите контроллер обычным способом Windows (USB или Bluetooth). Убедитесь, что система его видит.
2. Откройте настройки Controlify в игре. Выберите устройство, проверьте кнопки и стики, мёртвые зоны, чувствительность и инверсию; сохраните настройку.
3. Назначьте нужные действия модов в интерфейсе Controlify. Для редких действий используйте радиальное меню. Проверьте отдельно зум, прицеливание, перезарядку, паркур и меню.
4. Проверьте переход обратно на клавиатуру/мышь, отключение и повторное подключение устройства, сохранение настроек и повторный вход.

[Автор Controlify](https://modrinth.com/mod/controlify) заявляет также поддержку нестандартных джойстиков через сопоставление с геймпадом или собственные назначения. **Конкретная модель устройства пока не испытана**. Аналоговые крен/тангаж/рыскание/тяга конкретного самолёта Superb Warfare/будущего мода #12 не считаются готовыми от одной установки Controlify; нужна отдельная проверка интеграции самолёта и его осей. Схемы с личными GUID устройств и пользовательские конфиги в пакет не включаются.

## Маршрут игрового теста

- Новый мир: удержание/отпускание Z, несколько прокруток в обе стороны, возврат FOV. Без Z колесо переключает панель; инвентарь/меню работают обычно.
- Переназначить Z, изменить чувствительность, сохранить/перезайти. Существующие настройки должны сохраниться после повторного импорта через GUI.
- TaCZ: F8, перезарядка, прицеливание; Xaero: F9; ParCool и броня со способностями: нет нежелательного двойного действия на R/C.
- Forgematica: меню/сочетания, установка схемы, отсутствие блокировки новой схемой управления.
- Xbox/джойстик: базовые оси и кнопки, меню и инвентарь, действия модов, отключение/подключение; затем конкретный самолёт и проверка осей.
- Сравнить FPS/время кадра с прежней установкой на той же сцене. Подключиться к серверу без клиентских модов управления, проверить синхронизацию и повторное подключение.

#13 остаётся открытой до полной проверки схемы, контроллера и авиационных осей. #18 требует реального игрового подтверждения колеса, возврата FOV и сохранения настроек. Автоматическая сборка не заменяет эти испытания.
