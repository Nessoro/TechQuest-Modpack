# TechQuest Hybrid Warfare — дополнение к оригинальной броне Superb Warfare

**Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21.** Черновой PR #51; в main и официальный установщик не включено. **Не проверено запуском Minecraft.**

## Принцип: никаких новых текстур и моделей

Мод **не создаёт новых предметов брони** и **не содержит новых PNG, UV-развёрток, 3D-моделей или ресурспаков**. Сохраняются оригинальные предметы, иконки, Bedrock-модели и текстуры авторов Superb Warfare 0.8.9.2:

- `superbwarfare:ru_helmet_6b47` / `superbwarfare:ru_chest_6b43`
- `superbwarfare:us_helmet_pasgt` / `superbwarfare:us_chest_iotv`
- `superbwarfare:ge_helmet_m_35`

Оригинальные шлемы и жилеты остаются полностью узнаваемыми. Новые TechQuest-штаны и ботинки, Tactical Blue V2, Factory/Urban/Arctic/NightOps и генерируемые текстуры **удалены из аддона**.

## Объединение в кузнечном столе (20 рецептов)

**Незеритовый кузнечный шаблон + оригинальная броня Superb Warfare + технологическая броня соответствующего слота → та же оригинальная броня с компонентом `techquest_hybrid:technology`.**

| Технология | Шлем-донор | Бронежилет-донор |
| --- | --- | --- |
| IC2 Nostalgia | `ic2:quantum_helmet` | `ic2:quantum_chestplate` |
| Modern Industrialization | `modern_industrialization:quantum_helmet` | `modern_industrialization:quantum_chestplate` |
| Mekanism | `mekanism:mekasuit_helmet` | `mekanism:mekasuit_bodyarmor` |
| Oritech | `oritech:exo_helmet` | `oritech:exo_chestplate` |

Рецепты генерируются `scripts/generate_assets.py`. **Проверить точные ID доноров в игровом реестре**, особенно IC2 local.26. Исходный Item ID, текстура и трёхмерная модель Superb Warfare не меняются. Сохраняются компоненты базового предмета, включая прочность, зачарования, данные бронепластин и ранее нанесённую отделку. Энергия и внутренние модули донора **не переносятся**, донор расходуется; не использовать дорогую броню в основном мире до тестов.

Если одинаковой технологией улучшены шлем и жилет, включается лёгкий бонус комплекта: IC2 — огнестойкость, MI — Сопротивление I, Mekanism — дыхание под водой, Oritech — скорость I. Это не перенос оригинальной механики EU/FE, MekaSuit или квантовых модулей.

## Перекраска через Armor Trim Templates

В тег `minecraft:trimmable_armor` добавлены пять оригинальных предметов Superb Warfare. Используйте **обычный шаблон отделки из Minecraft + броню Superb Warfare + материал цвета** в кузнечном столе. Это отдельная операция от объединения с технологической бронёй.

Клиентский совместимый mixin для SimpleBedrockModel V2 использует `minecraft:trim` и применяет **цветовой фильтр к оригинальной текстуре**, не создавая её копию. Поддержаны основные ванильные материалы (золото, алмаз, редстоун, лазурит, изумруд, железо, медь, кварц, незерит, аметист). Без trim цвет и вид оригинала не меняются.

**Ограничение:** на нестандартной Bedrock 3D-геометрии Superb Warfare сложный орнамент ванильного шаблона не проецируется; шаблон выбирает **цвет всей брони**, а не рисует обычные узоры Vanilla Armor Trim. Точный визуальный результат и Mixin требуют проверки в реальном клиенте Minecraft 1.21.1 с закреплённым Superb Warfare, потому что встроенная версия SimpleBedrockModel может отличаться от открытых исходников.

## Проверка и интеграция

```bash
cd addons/hybrid-warfare-armor
python scripts/generate_assets.py
python -m unittest discover -s scripts -p 'test_*.py' -v
gradle build
```

Компиляция проверяет исходники, а тесты — JSON/сохранение исходных ID и отсутствие новых ресурсов. Не объявлять поддержку окраски, перенос энергии или стабильную работу сервера подтверждённой без игрового теста: попробовать все 5 моделей на клиенте, цвет материала отделки, сохранение/перезаход, заряд, бронепластины, и dedicated server. Сохранить PR черновым до результатов.
