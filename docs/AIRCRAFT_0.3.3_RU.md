# Дополнительные самолёты 0.3.3 — задача #12

**Приоритет владельца: сначала самолёты, затем геймпад.** После объединения PR #20 текущая ветка `feat/bosses-parcool-0.3.3-prep` содержит существующую 0.3.3 с исправлениями установщика, зумом и Physics Mod. Профиль остаётся один — Optimized. Это кандидат для испытаний, **не проверенный запуском Minecraft**.

## Что включено для теста

MCHeli [MODERN PORT] для Minecraft 1.21.1 / NeoForge ≥21.1.235 / Java 21. Закреплён оригинальный Modrinth version ID `5LbFIXGp`: API и JAR указывают версию `1.0.0`, имя файла автора — `MCHeli-1.21.1-1.1.0.jar`. Это расхождение сохранено в отчёте; файл не переименовывается и не выдаётся за другую версию.

Это проверка наличия данных, **не подтверждение работоспособности каждой модели**. Каталог `planes` содержит 51 определение, включая служебные/плавучие машины: это не 51 испытанный самолёт. F-16 и Су-57 в этом JAR не подтверждены. Существующие A-10A/J-16/AC-130H из Superb Warfare и Incoming сохранены.

Мод обязателен на клиенте и сервере этой ветки, версии должны совпадать. По JAR требуются только Minecraft/NeoForge; отдельные библиотеки не добавляются. Mixins-конфиг содержит только клиентский `CameraMixin`; это не исключает конфликты камеры с другими модами в игре.

**Ограничения:** автор называет порт альфой; штатных рецептов самолётов для выживания пока нет. Первое испытание — Creative. Рецепты и баланс TechQuest следует добавлять после проверки техники, чтобы не привязывать прогрессию к неисправной модели. Авиация использует собственные топливо/боеприпасы; совместимость с запасами Superb Warfare/Incoming не предполагается.

## Установка без консоли

1. В [Actions ветки](https://github.com/Nessoro/TechQuest-Modpack/actions?query=branch%3Afeat%2Fbosses-parcool-0.3.3-prep) выберите успешную сборку нужного коммита и Windows GUI Installer. Проверьте также Security Audit того же коммита; предыдущие артефакты других веток MCHeli не содержат.
2. Установите через GUI в **новую папку**, используйте официальный Minecraft Launcher с NeoForge 21.1.264 и Game Directory этой папки. Python и консоль игроку не нужны. [Подготовка NeoForge](NEOFORGE_FALLBACK_RU.md).
3. В новом творческом мире найдите предметы MCHeli в инвентаре/JEI. Начните с одного F-22A либо F-14D, поставьте на свободную площадку правой кнопкой по блоку. Не переносите основной мир в эксперимент.
4. Для сервера используйте комплект именно этой сборки. До запуска администратор вручную принимает Minecraft EULA; автоматическое согласие не добавлено.

## Управление для первого испытания

По документации автора: W/S — тяга, A/D — рыскание, мышь — тангаж/крен, левая кнопка — огонь, F — смена вооружения. На закреплённом JAR зарегистрированы дополнительные действия MCHeli: G — меню машины, H — предыдущее кресло, левый Alt — свободный обзор, R — режим стрелка, C — его зум, M — переключение свободного обзора, V — ловушки. Фактическое поведение проверяется в игре.

Эти G/H/R/C/M/V пересекаются с существующими модами. Обработчик MCHeli проверяет нахождение игрока в своей технике, но это **не доказательство отсутствия двойных действий** остальных модов. Перед полётом откройте Настройки → Управление → MCHeli и Controlling; при необходимости назначьте свободные клавиши. Исходные назначения остальных модов здесь не меняются. Наш статический KeyMapping-аудит видит фабрику MCHeli как unresolved и не покрывает все семь вызовов её помощника; реальные назначения выше проверены отдельно по байткоду.

Геймпад отложен до проверки выбранной авиации. Controlify не добавляется.

## Маршрут проверки

- [ ] Клиент дошёл до главного меню; новый мир загружается без ошибок ресурсов/моделей.
- [ ] По одному F-22A, F-14D, F-35 и МиГ-29: создание, посадка/выход, заправка и пополнение боезапаса через меню.
- [ ] Руление, взлёт, устойчивый полёт, камера, посадка, повторный вход в мир; нет двойных действий клавиш с TaCZ/ParCool/картой.
- [ ] Пулемёт и ракеты, попадание/урон и связь с разрушениями/Physics Mod: сначала один самолёт и обычный боеприпас, затем совместная сцена с Superb Warfare/Incoming. Ядерные испытания не нужны для первого полёта.
- [ ] Выделенный сервер дошёл до `Done`; два клиента видят модель, движение, пассажиров и попадания одинаково. Вход/выход и повторное подключение работают.
- [ ] Сравнить одинаковую сцену до/после: время кадра/FPS, память после прогрева; отдельно серверное время тика/TPS с 1 и 3 самолётами. Начать со штатных Fast/6/5/60, без шейдеров. 74.2 МБ JAR не являются оценкой потребления RAM.

При ошибке нужны модель, действие, commit сборки и `latest.log`/crash-report без личных данных. #12 остаётся открытой до этих испытаний; successful CI подтверждает сборку, а не полёт.

## Источники и отложенные варианты

- [Оригинальный MCHeli на Modrinth](https://modrinth.com/mod/mcheli-modern-port/version/5LbFIXGp), [исходники порта](https://github.com/ThatSoulyGuy/MCHeli). SHA-512/SHA-1, размер, список моделей и диапазоны: [`mcheli-candidate.json`](../compat/aircraft/mcheli-candidate.json).
- В Modrinth указана LGPL-3.0-only, внутри оригинального JAR — All Rights Reserved. Противоречие зафиксировано без самовольного выбора лицензии. В репозиторий/пакет не включаются сторонние JAR, модели или текстуры: `.mrpack` содержит ссылку на оригинальное скачивание и хеши. На изменение/перепубликацию этих файлов разрешение не предполагается.
- **AshVehicle `SIPuXN84` не добавлен:** в опубликованном JAR вызовы `VehicleEntity.gearRot(float)`, `RenderHelper.isInGui()`, старых перегрузок `ProjectileTool.causeCustomExplode(...)` и `Builder.damageMultiplier(float)` не соответствуют Superb Warfare 0.8.9.2. [`Зафиксированные примеры`](../compat/aircraft/ashvehicle-rejected.json). Публичная исходная ветка содержит миграционные изменения, но её нельзя приравнивать к проверенному опубликованному JAR. Superb Warfare не понижается.
- **Modern Fighters [IA] 0.0.8**: девять современных моделей, но нужны Immersive Aircraft и отдельно Homing Missiles [IA] для вооружения; авторская доставка CurseForge и ARR. Пока не выбран, чтобы не добавлять одновременно несколько новых авиационных систем.
- DragonRise остаётся прежним неактивным кандидатом, без подтверждённого оригинального файла. McWW3 без исходников не считается перенесённым.
