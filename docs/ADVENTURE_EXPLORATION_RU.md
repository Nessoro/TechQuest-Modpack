# TechQuest 0.3.3 — Adventure & Exploration (эксперимент)

**Цель:** уменьшить процент технологических модов за счёт содержательного наполнения приключений и исследования, не удаляя промышленное ядро BuildCraft / IC2 Nostalgia / Create / Mekanism / Modern Industrialization / AE2. Существующий пользовательский успешный тест клиента и Tailscale относился к ПРЕДЫДУЩЕЙ версии в плоском мире, а не к этой ветке.

Они закреплены как обязательные для **экспериментальной ветки** для предотвращения их незаметного пропуска; нужные библиотеки должны добавляться автоматическим резолвером Modrinth. Окончательная клиентская и серверная совместимость требует игровых испытаний.

## Изменение жанров (по объявленным игровым модам, а не игровому времени)

При одинаковой классификации модов в `modlist.json`, включая отмеченные необязательными, manual IC2 и внешние Incoming/AMW:

| Направление | До (0.3.3 тестовая) | После этого изменения |
| --- | ---: | ---: |
| Технологии / хранение | 11 из 31 — 35,5% | 11 из 44 — **25,0%** |
| RPG / мобы / боссы / мир / приключения | 11 из 31 — 35,5% | 21 из 44 — **47,7%** |
| Исследование / комфорт / перемещение | 3 из 31 — 9,7% | 4 из 44 — **9,1%** |
| Военное / разрушения (включая optional AMW) | 6 из 31 — 19,4% | 8 из 44 — **18,2%** |

**Совокупная доля приключений и исследования: 25/44 = 56,8%.** Процентные доли отражают жанры позиций из манифеста, включая необязательные, но не учитывают технические библиотеки, FPS-моды и служебные утилиты. Количество технологических модов не изменено; мы снизили **их относительную долю**.

## Маршрут приключений для геймплея

1. **Старт:** исследование окрестностей, компас, руины, артефакты и обычный общий лут в сундуках; с друзьями заранее договоритесь о разделе сокровищ.
2. **Средний уровень:** крупные подземелья When Dungeons Arise и крепости YUNG's, подготовка снаряжения/лечения, бой с обычными боссами и Cataclysm.
3. **Новые измерения:** The Aether и Deeper and Darker, исследование биомов, существ и подземелий.
4. **Поздняя игра:** крепости Незера и Энда, сильные боссы; развитие техники становится вспомогательным способом обеспечить экспедиции снаряжением и ресурсами.

## Измерения и производительность

- [ ] CI: Modrinth API разрешает все 8 модов и обязательные зависимости; zip и SHA-1/SHA-512 проверены. Это не означает, что игра стартует.
- [ ] Клиент: Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21; проверить меню, одиночный мир и загрузку новых измерений.
- [ ] Выделенный сервер: загрузка всех модов, создание/сохранение нового обычного мира, затем добровольное принятие EULA и multiplayer.
- [ ] Совместимость с TerraLith (если установлен), Lithostitched, YUNG's, When Dungeons Arise; убедиться, что структуры не налезают друг на друга и генерация не зависает.
- [ ] Проверить наличие разных драконов Wyrmroost, приручение/полёт и гигантских монстров; тестировать в новых чанках, не на старом Superflat.
- [ ] Tailscale: подключение 2–8 игроков, посещение обоих измерений, бои с боссами, повторный вход.
- [ ] На сервере: `/spark` профилирование, TPS/tick time при генерации новых чанков, при наличии заводов и в боевых сценах с Incoming/AMW.
- [ ] На клиенте: FPS и память на разных конфигурациях (6, 8, 12 ГБ выделенной RAM), генерация чанков и подземелья; прежние тесты Superflat не эквивалентны.
- [ ] Бэкап исходного мира до любого обновления, первая проверка строго в новом мире. Никогда не устанавливать на старую работающую версию поверх существующих JAR.

Серверный режим, FPS и совместимость **не проверены** на текущем наборе. Не публиковать stable-release, пока эти пункты не выполнены.
