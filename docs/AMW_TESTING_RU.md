# AcceleratedMcWarfare (AMW) — эксперимент для TechQuest 0.3.3

**Статус:** подготовлена интеграция ручной установки, но игровой запуск **не подтверждён**. Ветка тестовая, не переносите её поверх рабочего мира.

- Официальный мод: https://www.curseforge.com/minecraft/mc-mods/amw/files/9298161
- Автор: QQbig; File ID: **9298161**, файл: `acceleratedMcWarfare-1.0.4..jar`, версия: **1.0.4 Alpha** от 23.10.2026.
- Требования автора: Minecraft **1.21.1**, **NeoForge**, **Java 21**, **GeckoLib 4.8.4**. На CurseForge в автоматической таблице зависимостей пусто, но в авторском описании GeckoLib явно назван: ориентируйтесь на описание.
- Лицензия: **All Rights Reserved**. JAR в GitHub или `.mrpack` не публикуется. Отдельный прямой CDN-доступ может требовать авторизацию CurseForge.
- **Один и тот же JAR должен быть на клиенте и выделенном сервере.** Используйте одинаковые версии GeckoLib и остальных игровых модов.
- В `modlist.json` GeckoLib добавлен как обязательная библиотека для этой тестовой ветки; версия 4.8.4 указана автором AMW, но сборщик выбирает общую совместимую версию для всей сборки. Результат проверяется игровым запуском.

## Как установить клиент через официальный Minecraft Launcher

1. Используйте отдельную новую папку для тестового TechQuest 0.3.3. Установите сборку через экспериментальный Windows GUI EXE, скачанный из GitHub Actions этого PR.
2. Скачать оригинальный JAR **только** по указанной официальной странице CurseForge (без зеркал и перепаковок). Папку установки не смешивайте с рабочей версией.
3. В GUI нажмите кнопку **«3. Добавить AMW»**, выберите скачанный файл. Установщик проверит имя, ограничения размера, структуру архива и наличие NeoForge metadata, затем **скопирует** его в `mods/` без замены существующих файлов.
4. SHA-256 скачанного файла записывается в `TECHQUEST_AMW_IMPORT.txt`. **Это только локальный отпечаток, а не сверка с подписью/хешем автора**. Не считать происхождение криптографически подтверждённым.
5. Запустите Minecraft Java 1.21.1 / NeoForge 21.1.264 / Java 21. Проверьте главное меню и лог `latest.log`.

## Сервер / Tailscale

1. Скопируйте тот же оригинальный файл `acceleratedMcWarfare-1.0.4..jar` в `server/mods/` и убедитесь в наличии GeckoLib на сервере. Не смешивайте с ошибочными/неподходящими файлами Forge.
2. При необходимости используйте локальный SHA-256, чтобы убедиться, что файл на обеих машинах идентичен.
3. Прежде чем подключать друзей, сделайте резервную копию мира и согласитесь с Minecraft EULA в отдельном сервере.
4. Проверьте вход через Tailscale, одинаковые конфигурации и повторные подключения.
