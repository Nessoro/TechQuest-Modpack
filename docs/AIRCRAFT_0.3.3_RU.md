# Военная авиация TechQuest 0.3.3-alpha

**Решение владельца от 08.11.2026:** MCHeli Modern Port — **«не нужен»**, исключён из обязательного клиентского и серверного набора, закреплённых версий и каталога. TaCZ также исключён по причине **«не нужен»**.

В составе остаются **Superb Warfare 0.8.9.2** и **Incoming: Air Strikes & Nukes 3.10.4**. Отдельный необязательный импорт AcceleratedMcWarfare (AMW) сохранён; его совместимость требует ручного игрового теста.

Запрос на современные боевые самолёты [#12](https://github.com/Nessoro/TechQuest-Modpack/issues/12) остаётся открытым: не считать ранее добавленный, а теперь удалённый MCHeli основанием для закрытия задачи. Поддержка геймпада только при пилотировании самолёта [#13](https://github.com/Nessoro/TechQuest-Modpack/issues/13) пока не реализована.

После обновления используйте **новую папку** установки: существующий `mods/` и ручные пользовательские дополнения установщик автоматически не очищает. Не переносите экспериментальные JAR из прежней сборки.
