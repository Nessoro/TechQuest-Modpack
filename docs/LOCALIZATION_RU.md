# Русификация TechQuest

## Решение владельца и правила перевода

Цель — **полный перевод всех видимых игровых текстов** сборки, включая
предметы, блоки, подсказки, достижения, интерфейсы, настройки и руководства.

- Приоритет: технические моды, затем остальные моды TechQuest.
- Названия модов и брендов (`BuildCraft`, `Create`, `Mekanism`, `AE2`) сохраняются.
- Технические обозначения (`EU`, `FE`, `RF`, `MJ`, `mB`, `TPS`, `FPS`) не переводятся.
- Идентификаторы и ключи локализации, пути, рецепты и данные сохранений не меняются.
- Язык выбирается **вручную**: «Настройки → Язык → Русский (Россия)».
- Существующие переводы модов сохраняются; новые строки только дополняют
  отсутствующее или исправляют конкретные ошибки.
- Игровая проверка владельцем проводится **после завершения всей локализации**,
  а не после отдельных этапов. Офлайн-тесты и CI продолжаются независимо.

## BuildCraft Community Edition 8.0.23 — полный набор ключей

В `compat/techquest-compat/assets/buildcraft/lang/ru_ru.json` заполнены
**все 2002 игровых ключа** официального
[английского файла релиза 8.0.23](https://github.com/BCCE-team/BuildCraft/blob/8.0.23/source-shared/src/main/resources/assets/buildcraft/lang/en_us.json).
Служебный комментарий `_comment` не считается игровым ключом.

Использованы исходники переводчиков проекта
[BCCE-team/Localizations](https://github.com/BCCE-team/Localizations)
и собственные переводы TechQuest для отсутствующих строк. Сохраняются все
форматирующие маркеры и подстановки (`%s`, `%1$s`, `§` и т. п.).

Помимо интерфейсов локализован **218-страничный справочник BuildCraft**:
`compat/techquest-compat/assets/buildcraft/guide/text/ru_ru.json`.

Исходные переводы BCCE распространяются по
**Mozilla Public License 2.0 (MPL-2.0)**; текст лицензии и сведения
об изменениях находятся в
`compat/techquest-compat/THIRD_PARTY_LICENSES/`.
Оригинальный JAR BuildCraft не перепаковывается.

Оба файла входят в `techquest-compat-1.0.0.jar`, создаваемый
`build_pack.compatibility_jar()`. При выборе языка «Русский» NeoForge
должен подхватывать ресурсы. **Отображение в реальном клиенте ещё не проверено**.

## Обязательный аудит перед завершением

`scripts/audit_localizations.py` сравнивает английские и русские
`assets/*/lang/*.json` во всех скачанных JAR, включая локализации внутри
TechQuest Compatibility. Он формирует
`output/localization-coverage.json` с пропущенными ключами по пространствам
имён. Он не запускает Minecraft и не переписывает моды.

Команда для разработчика после сборки (не для обычного игрока):

```bash
python scripts/audit_localizations.py --mods output/client/mods --strict
```

Аудит без `--strict` автоматически вызывается из `build-alpha.yml`
после скачивания клиентских модов и публикуется в артефактах CI.
Результат «0 пропущенных ключей» означает **структурное покрытие**,
но ещё не гарантирует смысловую точность, наличие русских текстов внутри
нестандартных файлов руководств или фактическое отображение в игре.

## Оставшаяся работа

Массовые пропуски пока обнаружены у Mekanism: для текущей ветки его
исходников `1.21.x` — **1347** ключей, у Mekanism Generators —
**143** ключа. Их нужно заполнить и затем сверить с реально закреплёнными
JAR. Для IC2: Nostalgia и остальных модов полный аудит ещё не завершён.

Нельзя считать весь TechQuest переведённым, пока не проверены все
клиентские моды, нестандартные руководства, категории и настройки, а
результаты CI не показывают допустимое покрытие. Слияние и выпуск
версии `0.3.3.N` проводятся только после согласованных проверок.
