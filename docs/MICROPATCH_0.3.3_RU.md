# TechQuest 0.3.3 — микропатч: хранение, добыча и совместный World Tier

Кандидат для испытаний Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21. Это изменение состава модпака, поэтому установка в старый мир требует резервной копии.

## Моды

- Sophisticated Storage 1.6.16.2222: улучшаемые сундуки, фильтры и автоматизация. Существующий Iron Chests остаётся.
- Inventory Profiles Next 2.2.4, libIPN 6.6.3 и уже закреплённый Kotlin for Forge 5.12.0: сортировка инвентаря и сундуков, только клиент.
- FTB Ultimine 2101.1.15 и FTB Library 2101.1.39, а также Architectury API 13.0.11: добыча жил, туннели и формы 3x3. Оба FTB JAR загружаются с официального Maven и проверяются по SHA-256, клиент и сервер.
- В Project MMO оставлена прокачка кирки и навыки; собственный Vein Mining отключается серверным datapack через data/pmmo/config/server.json.

## Совместный World Tier Apotheosis

Встроенный Open Loader datapack хранит максимум в scoreboard tq_worldtier. Каждый 20-й тик проверяет *активный* уровень игроков по сохранённому в NeoForge attachment apotheosis:world_tier значению и повышает глобальный максимум. Штатная команда apoth set_world_tier применяется к другим онлайн-игрокам. Новый игрок получает уровень после входа. Ручное понижение ниже общего максимума отменится в течение секунды.

Решение следует из исходного кода Apotheosis 8.9.0: WorldTier.setTier(player, tier) синхронизирует клиента и обновляет модификаторы. Требуется проверка настоящим сервером: сериализация attachment может отличаться, команды функций и datapack могут конфликтовать с чужими настройками. Не обещаем, что автоматически работает, пока не проведён тест на нескольких игроках.

## Безопасная проверка

1. Остановите сервер. Скопируйте весь мир, mods, config и defaultconfigs. Не удаляйте старые сундуки.
2. Примените новый клиентский и серверный пакет. Новые инструменты сортировки IPN не нужны серверу.
3. Создайте и улучшите новый сундук Sophisticated Storage. Старые Iron Chests должны сохраниться.
4. Проверьте Ultimine на шахте: режимы формы, кирку и цепочку руды. Откройте настройки клавиш, если пересекаются с зумом.
5. Проверьте, что PMMO Vein Mining не работает, но уровни навыков начисляются как раньше.
6. Два игрока: первый активирует Frontier через меню, второй должен автоматически получить Frontier. Повторить с Ascent и после перезагрузки сервера, затем проверить нового третьего игрока.
7. Если опыт, предметы или уровни отличаются от ожидаемых, вернитесь к бэкапу и сохраните обезличенные логи для диагностики.

Дополнительная оговорка: серверный файл PMMO server.json содержит полную конфигурацию Codec. При наличии сторонних PMMO datapack-правок его нужно объединить с их значениями вручную; иначе приоритет ресурсов может переопределить соответствующие игровые параметры.

## Исправление запуска Better Zoom

При реальном запуске расширенной сборки обнаружено исключение `Cannot get config value before config is loaded` в Better Zoom 3.1.1. В TechQuest Compatibility добавлен клиентский Mixin, пропускающий ранний тик Better Zoom до загрузки `Config.SPEC`; после загрузки обычные зум на Z и колесо должны оставаться прежними. Подтверждение обязательно включает запуск реального клиента до главного меню и тест зума в мире, а не только проверку Python.

**Совместимость Sophisticated Core:** первоначальный Storage 1.4.21.1123 давал `NoSuchMethodError` с уже закреплённым Core 1.5.31.2460. По официальному Modrinth зафиксирован более свежий Storage 1.6.16.2222 от 4 ноября 2026; требуется повторный реальный запуск клиента, прежде чем считать пару совместимой. Sophisticated Backpacks и Core пока не обновлялись.

## Обновление существующей установки без потери настроек

Новые серверные настройки помещены в **новый отдельный файл** `config/openloader/packs/techquest_micropatch_033.zip`, а не в прежний `techquest_starter_guide.zip`. Установщик и Python bootstrap добавляют его при отсутствии, **не перезаписывая** существующие файлы, миры и прежние настройки. Для обновления уже существующего профиля установите новый пакет и проверьте наличие нового ZIP как у клиента, так и на сервере. Старый ZIP с путеводителем сохранится. Сделайте резервную копию перед обновлением; существующие datapack/PMMO настройки могут вступить в конфликт с новым полным PMMO server.json.

## Обновление без новых папок

Начиная с микропатча, Windows GUI-установщик поддерживает **обновление в той же папке TechQuest**. Укажите уже используемую папку, выберите «Установить / обновить» и подтвердите замену. Скачивание и проверка SHA завершаются до замены старого набора JAR. Устаревшие JAR не смешиваются с новыми: предыдущие файлы сохраняются в **одну** папку `.techquest-previous-mods` (обновляется при каждом следующем патче). При ошибке установки программа пытается вернуть предыдущие моды. `saves`, `options.txt`, `config`, `defaultconfigs` и данные карт остаются в прежней папке. Сторонние дополнения, например AMW, из старой папки модов автоматически не переносятся; после обновления их нужно установить повторно и проверить совместимость. При обновлении не требуется снова устанавливать NeoForge или изменять профиль Launcher, если его версия и путь не менялись. Перед обновлением всё равно рекомендуется отдельно сохранить мир.
