# Официальный TaCZ и 4 оружейных пака для TechQuest

**Статус: экспериментальная интеграция, не проверенная игровым запуском.** Работа ведётся в отдельной ветке; стабильную папку Minecraft не изменять.

## Основной мод

[TaCZ 1.2.0](https://modrinth.com/mod/timeless-and-classics-zero/version/O2Pfsh6w) официально выпущен для Minecraft Java 1.21.1 / NeoForge / Java 21 6 ноября 2026 года. Мод включён как **обязательный в тестовую ветку** и устанавливается клиенту и серверу с проверкой хешей, как остальные моды Modrinth.

Они являются ZIP-контентом TaCZ, а **не JAR-модами**. Все авторские ZIP опубликованы для 1.20.1. Их наличие в каталоге не означает полной поддержки 1.21.1.

## Установка без Python для обычных игроков

1. Запустите **тестовый** TechQuest Windows GUI Installer в отдельную пустую папку.
2. На CurseForge вручную скачайте **все четыре оригинальных ZIP** из списка выше, не распаковывайте и не переименовывайте.
3. В GUI нажмите **3. Импорт TaCZ ZIP** и выберите четыре архива. Установщик проверит имена, ZIP-структуру и лимиты размера, затем скопирует файлы в папку `tacz/`. **Автоматической проверки SHA-256 против публикации автора пока нет**; скачивайте только по указанным ссылкам.
4. В TaCZ 1.2.0 при необходимости вызовите `/tacz convert universal` — авторы добавили конвертацию паков 1.20.1 в формат 1.21.1. Проверьте каталог `tacz-converted/` и инструкцию команды. Не предполагайте, что преобразованные файлы можно использовать до проверки рецептов и зависимостей.
5. Для игры с друзьями используйте одинаковые протестированные наборы оружейных паков и версию TaCZ на сервере и клиентах. На сервере оригинальные ZIP можно положить в `server/tacz/`. Автоматическая синхронизация не заменяет проверку загрузки и корректности рецептов.
