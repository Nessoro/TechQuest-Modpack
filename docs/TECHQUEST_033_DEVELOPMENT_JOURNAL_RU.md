> **Языковое правило проекта (14.11.2026):** все промпты, ТЗ, рабочие задания и инструкции для Codex или другого ИИ-чата писать **на английском языке**. > **Правило ведения журнала.** После каждого изменения в TechQuest обновлять эту страницу в том же PR или следующем документационном PR. Записывать принятые и отменённые решения, новые задачи, ссылки на PR/issues, фактически проведённые проверки, их результаты, проблемы и следующий шаг. **Нельзя подменять факт успешной сборки утверждением, что Minecraft проверен в игре.** Историю решений не затирать — добавлять новую датированную запись.

## Неприкосновенные решения владельца

1. **Сохранить TechQuest Compatibility 1.0.0:** исправления рецептов Create ↔ IC2 Nostalgia и ранней загрузки Better Zoom. **Удалить** TechQuest RPG Core, не возвращать Project MMO.
2. **Сохранить IC2: Nostalgia 21.1.0-local.26** в качестве основного IC2. Не заменять его на Refactored, не менять ID и сохранённые миры ради солнечных панелей.
3. **Отменено направление FTB Industrial Contraptions.** Не добавлять FTB Industrial, Colossal Reactors, Iskandert's Library и Fusion в новые патчи только ради реактора. Исследовательская [задача #33](https://github.com/Nessoro/TechQuest-Modpack/issues/33) закрыта как not planned.
4. **micro4:** Trash Cans + Pretty Pipes транспортируют **предметы**, в том числе предметы-блоки, но не передвигают поставленные блоки в мире. Не приписывать Pretty Pipes транспорт жидкости или энергии.
5. **micro5:** Iskander Rocket — отдельная ракета; он **не зависит от Iskandert's Library**. Не заявлять интеграцию с Incoming или Broken Arrow, пока её не реализовали и не проверили.
6. **micro6:** адаптировать аддон под существующий IC2 Nostalgia, с соблюдением лицензии и реальным EU-тестом, а не ставить неподходящий JAR от IC2 Refactored.
7. Сохранять один Optimized-профиль, версии Minecraft/NeoForge/Java, поддержку игры с друзьями, стандартный Minecraft Launcher и установку на Windows без Python или командной строки для обычного игрока.
8. Сохранять **saves**, **config**, **options.txt**, профиль Launcher. Любые обновления — с резервной копией и откатом; не публиковать релиз или не объединять PR без отдельного решения владельца.

## Результаты и оставшиеся проверки

### micro3
- На уровне кандидата удалена генерация RPG Core и сохранён Compatibility. В PR есть регрессионные тесты/проверки манифеста.
- **Не считать решённой** отдельно сообщавшуюся проблему, когда при добыче одного блока ломается колонна сверху. Нужен воспроизводимый тест Ultimine/Physics и диагностика, в том числе на прежних профилях с сохранёнными конфигами.
- Перед приёмкой: реальная проверка клиента/сервера, рецептов Create ↔ IC2, Better Zoom, безопасного обновления и отката.

### micro4
- Зафиксированы **Trash Cans** (Modrinth 4QrnfueM, версия lSKYKJdm) и **Pretty Pipes** (XExdLWCQ, версия lrhbGGSe); библиотеки Trash Cans закреплены.
- Colossal Reactors и его уникальные зависимости исключены после уточнения владельца.
- Перед приёмкой: работающие сценарии сундук → трубы → сундук/мусорка, фильтры, разные контейнеры, сервер, TPS/FPS, защита от случайного удаления.

### micro5
- Зафиксирован **Iskander Rocket Mod 2.0.1** (Modrinth XUogRnhj / M1b2lYax) с точным SHA-512 и установкой клиента/сервера.
- Внеиз игрового CI были проведены сборочные/метаданные проверки; реальный безопасный пуск и работа на сервере требуют доказательства.
- Перед приёмкой: запуск одиночной ракеты в новом мире, карта разрушений, перезапуск, сохранения, дальняя цель и нагрузка, проверка с Incoming без одновременных залпов.

### micro6
- [Задача #32](https://github.com/Nessoro/TechQuest-Modpack/issues/32) — солнечные панели для **Nostalgia**, а не Refactored.
- Статический аудит оригинального Advanced Solar Panels 1.1.8 (официальный CurseForge file ID 9525863) показал **48 Java-классов** и **19 обращений к API me/halfcooler/ic2r**; для одного класса нет простого соответствия в Nostalgia при гипотетическом переименовании пакета. **Это не готовый перенос.**
- Аудит и отдельные offline unit-тесты прошли в GitHub Actions. Настоящего солнечного JAR для Nostalgia в пользовательском наборе нет.
- Очередность: (A) исходники/лицензии/матрица Java API; (B) одна работающая Advanced Solar Panel, подключённая к EU-сети Nostalgia; (C) Hybrid, Ultimate Hybrid, Quantum; (D) рецепты, JEI/Patchouli, сервер и проверка сохранения; (E) интеграция в GUI/.mrpack с SHA-512 только после успешных игровых проверок.

### Общие проверки для выпуска каждого патча
- `python -m unittest discover -s tests -v` и `python build_pack.py`; проверка скачиваний, SHA-512, side metadata и .mrpack.
- Windows EXE self-test, отдельно работающая установка в новой папке, повторная установка и откат с сохранением пользовательских файлов.
- Реальный клиент до меню, создание/пересохранение мира, проверка базовых Create/IC2/BuildCraft интеграций.
- Dedicated server до `Done` и вход пользователя **только после явного принятия EULA**.
- Раздельные реальные замеры FPS и TPS; скриншоты/логи приложены к тому же commit SHA. **Успех unit-тестов и CI не означает успешного запуска Minecraft.**
