# Установка NeoForge при недоступном Maven — задача #9

Изменения тестовой ветки `fix/neoforge-zoom-controls-0.3.3`. Платформа остаётся **Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21**. Клиент устанавливается через Windows GUI и официальный Minecraft Launcher, без Python и консоли.

## Как устанавливать

1. В официальном Launcher установите и запустите **обычную Minecraft 1.21.1** один раз, затем закройте игру. Это создаст исходную версию в папке Launcher.
2. В TechQuestInstaller установите моды в **новую отдельную папку**, как раньше.
3. Нажмите **«2. Установить NeoForge»**. Выберите **корневую папку официального Launcher**, обычно `%APPDATA%\.minecraft`, содержащую `versions/1.21.1/`. Папка модпака из шага 2 для этого шага не подходит; GUI объяснит ошибку.
4. Установщик проверит/скачает официальный JAR NeoForge и **70 библиотек** из его `install_profile.json` и `version.json`. Прогресс показывает имя файла и источник. Подготовку можно отменить.
5. Откроется обычное графическое окно NeoForge. Выберите **Install client** и **ту же корневую папку Launcher**, которую указали в шаге 3.
6. После установки откройте официальный Minecraft Launcher → профиль NeoForge 21.1.264 → Изменить → **Game Directory / Папка игры**. Здесь укажите уже **отдельную папку модпака** из шага 2.

Для скачивания исходной Minecraft и недостающих официальных данных версии нужен доступ к серверам Mojang. Подготовка библиотек устраняет зависимость этой части установки от доступности основного Maven; далее работает официальный установщик NeoForge.

## Источники и целостность

- Основной источник остаётся `maven.neoforged.net`; для исходных библиотек Minecraft используется также их официальный `libraries.minecraft.net`.
- Проверенный резерв — `maven.creeperhost.net`. [CreeperHost сотрудничает с NeoForge и обслуживает Maven](https://www.creeperhost.net/partner/neoforge-aww). Для библиотек Minecraft предусмотрены также официальный NeoForge Maven и Maven Central по тому же пути артефакта.
- **SHA-512 установщика закреплён внутри EXE**. Для его проверки не требуется сначала скачивать `.sha512` с недоступного хоста. Все 70 путей, размеров и SHA-1 библиотек извлечены из этого проверенного оригинального JAR; CI сравнивает план с ним повторно.
- Резерв используется только как транспорт: его ответ обязан совпасть с закреплённым хешем и размером. Несовпавший файл не устанавливается и не запускается. Сторонние JAR не включены в репозиторий или EXE.
- После ошибки соединения/тайм-аута хост пропускается для остальных файлов текущей попытки, чтобы не повторять одинаковое ожидание 70 раз. Для отдельного запроса действует ограничение 30 секунд.

## Если загрузка прервалась

Повторите ту же кнопку после восстановления доступа. Проверенные файлы используются повторно. Повреждённый файл в собственном кеше установщика можно скачать заново; уже существующая библиотека Launcher с другим содержимым **не перезаписывается автоматически**. Диалог назовёт точный путь: сохраните резервную копию и восстановите соответствующую установку через Launcher, затем повторите попытку.

Если основной и резервный источники недоступны, GUI показывает имя нескачанного файла, источник и причину. Непроверенный установщик не запускается. При обращении за помощью достаточно этого сообщения и версии EXE; личные файлы Launcher и учётные данные публиковать не нужно.

## Область проверки

Пройдены тесты общего C# загрузчика с недоступным источником, неверным хешем, существующим изменённым файлом, повторным использованием кеша и отменой. Реальные сетевые прогоны CI подтвердили скачивание и хеши установщика + 70 библиотек как при доступном Maven, так и при его намеренной недоступности, с использованием CreeperHost.

В workflow `Verify NeoForge installer fallback` добавлен отдельный Windows-тест: временная обычная версия 1.21.1, подготовка библиотек общим кодом GUI и реальный официальный `--installClient` с недоступным Maven. Итог этого теста фиксируется в PR и Actions. Он проверяет создание версии/профиля, **не запуск Minecraft и не ручные клики в графическом окне**. Игровой smoke-test и испытание кнопки на пользовательском Windows остаются отдельными пунктами #9.
