# Участие в TechQuest

Спасибо за помощь! Заявки принимаются через GitHub Issues: шаблон **«Ошибка в сборке»** для проблем и **«Предложить мод»** для идей.

Перед публикацией проверьте похожие обращения. Для проблем укажите версию, клиент/сервер, точные шаги воспроизведения и результат. Не публикуйте публичные IP, токены, ключи доступа, адреса игроков и неотредактированные логи.

Для предложения нового мода по возможности укажите прямую ссылку на авторский источник, поддержку **Minecraft 1.21.1 NeoForge**, зависимость от других модов, лицензионные ограничения и причину включения.

Для исправлений создавайте Pull Request с коротким описанием, тестами и ссылкой на Issue. Изменения большого пакета проверяются на чистом сервере и клиенте с одинаковыми версиями. Не добавляйте сторонние JAR-файлы в репозиторий.
