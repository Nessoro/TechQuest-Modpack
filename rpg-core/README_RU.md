# TechQuest RPG Core 0.1.0 — собственный маленький мод (NeoForge lowcodefml)

Это **самостоятельный мод**, созданный на основе поддерживаемого NeoForge загрузчика `lowcodefml`: JAR содержит `META-INF/neoforge.mods.toml` и оригинальные серверные datapack-функции, **не содержит заимствованных классов Project MMO**. Он устанавливается в клиент и на сервер. Minecraft 1.21.1, NeoForge 21.1.264, Java 21.

## Поведение
- Полностью **нет** PMMO: навыков, опыта, уровней, требований, Vein Mining, дополнительных дропов, командного XP, разбора предметов и уведомлений.
- Сохраняются **не числовые уровни PMMO**, а **три этапа наград** за ванильные достижения: железные инструменты → Haste I; огненный стержень → Resistance I; победа над драконом → Speed I. Эффекты кратковременные (7 секунд), автоматически продлеваются раз в 5 секунд. Они не изменяют механику разрушения блоков: Haste ускоряет обычную добычу, но не ломает соседние блоки.
- Мобы постепенно усложняются по **дням мира**: с 7-го дня Strength I; с 21-го Strength I + Resistance I; с 42-го Strength II + Resistance I. Боссы, нейтральные и модовые мобы намеренно исключены из первой версии. Это не PMMO scaling по уровню персонажа.
- Не добавляет GUI, обработчиков добычи или дополнительных тик-событий Java: запускает одну функцию каждые 100 тиков (~5 секунд), затем применяет эффекты только к загруженным сущностям из тега.

## Управление через стандартные команды (OP)
```mcfunction
scoreboard players set #enabled tqrpg_flags 0
scoreboard players set #perks tqrpg_flags 0
scoreboard players set #mobs tqrpg_flags 0
```
Верните значение 1 для включения. Scoreboard хранится в мире; отключение вступает в силу на следующем цикле (старые эффекты исчезают максимум через 7 секунд). После `/reload` флаги 0 не сбрасываются.

## Совместимость
- Нет прямой интеграции с внутренними уровнями/бонусами PMMO; сохранения навыков PMMO **не конвертируются**. Резервная копия обязательна.
- Прежний World Tier Apotheosis и отдельные RPG-моды остаются; собственные эффекты могут накладываться на их бонусы, поэтому требуется игровой тест баланса.
- Скрипты `minecraft:tick` и `minecraft:load` используют стандартные объединяемые function tags (не `replace=true`); это позволяет работать рядом с datapack micro1 для World Tier.
- Старый PMMO конфиг/датапак в существующем Game Directory может остаться без использования. Установщик не удаляет пользовательские конфиги автоматически.
- Чтобы убедиться, что все функции запускаются: `/function techquest_rpg:step`, посмотрите игровые логи на ошибки datapack. Для реального сравнения сломайте один блок без нажатия Ultimine.
